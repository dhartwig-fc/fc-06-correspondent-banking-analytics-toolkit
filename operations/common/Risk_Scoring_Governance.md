# Risk Scoring Governance

## Purpose

This document defines governance requirements for Correspondent Banking Analytics risk scoring models.

The objective is to ensure models remain effective, explainable and appropriately controlled.

---

## Governance Principles

Risk scoring models should be:

- Explainable
- Transparent
- Documented
- Tested
- Independently reviewed
- Periodically calibrated

---

## Model Ownership

### First Line

Responsible for:

- Model operation
- Threshold management
- Performance monitoring

### Second Line

Responsible for:

- Oversight
- Challenge
- Independent review

### Internal Audit

Responsible for:

- Governance assurance
- Control assessment

---

## Threshold Management

Risk thresholds should be documented.

### Example

| Score | Risk Level |
|---------|------------|
| 0-29 | Low |
| 30-59 | Medium |
| 60-79 | High |
| 80-100 | Critical |

Threshold changes should be formally approved.

---

## Performance Monitoring

Key metrics:

- Alert volume
- True positive rate
- False positive rate
- Conversion rate
- SAR referral rate

---

## Calibration Reviews

Calibration should occur:

- Quarterly
- Following significant model changes
- Following regulatory findings
- Following material performance deterioration

---

## Validation Requirements

Validation should assess:

- Data quality
- Model logic
- Threshold appropriateness
- Alert effectiveness
- Outcome consistency

---

## Change Management

Changes requiring approval:

- New scoring factors
- Weighting changes
- Threshold changes
- Data source changes

All changes should be version controlled.

---

## Governance Forums

Recommended governance forums:

- Financial Crime Analytics Committee
- Model Governance Forum
- Risk Committee

---

## Documentation Requirements

Each model should maintain:

- Methodology document
- Scoring framework
- Calibration history
- Change log
- Validation record

---

## Audit Requirements

Models should be auditable and capable of demonstrating:

- Risk rationale
- Decision transparency
- Governance oversight
- Performance monitoring
